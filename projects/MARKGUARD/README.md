## Как добавить сам EXE в GitHub

1. Открой эту папку на GitHub.
2. Нажми **Add file → Upload files** (при необходимости — **Add file** вверху репозитория, затем перейди в эту папку).
3. Перетащи **`MARKGUARD(4).exe`** с компьютера в область загрузки.
4. Добавь сообщение коммита, например `Upload MARKGUARD experimental build`.
5. Нажми **Commit changes** и убедись, что файл отображается в папке.

После загрузки GitHub будет хранить приложение рядом с этой документацией. Не публикуй приватные ключи, пароли, токены и чужие файлы вместе с EXE.

## Проверка целостности

В PowerShell на Windows:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\MARKGUARD(4).exe"
```

Результат должен совпасть с SHA-256 из таблицы. Совпадение означает только идентичность полученного файла; оно **не подтверждает безопасность**.
