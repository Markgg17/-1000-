## Включение GitHub Pages

1. Открой **Settings → Pages** в репозитории.
2. Выбери **Deploy from a branch**.
3. Установи **main** и **/(root)**.
4. Нажми **Save**. После завершения публикации открой адрес выше.

Сайт предназначен для статического хостинга GitHub Pages. Настройки Pages необходимо активировать отдельно, если они ещё не включены.

## Обновление

В этой версии старые файлы сайта удалены из актуального дерева ветки `main` и заменены новым порталом. Git-история прежних коммитов остаётся доступной. Старые отдельные репозитории, если они есть, не удалялись.

## Примечание

Приложения сохраняют данные в браузере пользователя; Creator Studio поддерживает экспорт и импорт резервной копии. STL-файлы следует проверять в слайсере перед печатью.
