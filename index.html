✨ Поделиться проектом

После проверки опиши свою работу. Откроется форма GitHub Issues с названием и описанием — файл автоматически никуда не загрузится.

Не добавляй пароли, личные данные, токены или чужие файлы. Публикация через GitHub Issues может потребовать входа в GitHub; автор проекта решает, что размещать публично.

🔐 Проверка безопасности

Локальный анализ показывает метаданные и хеш файла, но не определяет наличие вирусов. Для настоящего сканирования проверь файл в Защитнике Windows. При желании можно проверить хеш или файл через VirusTotal, учитывая, что загруженные туда файлы могут стать доступны сторонним исследователям.
